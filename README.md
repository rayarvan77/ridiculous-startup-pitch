# Ridiculous at First Glance, Real by the Second

One-sentence startup pitch for the [make.fun bounty](https://make.fun/bounty/u-po-pu-ridiculous-at-first-glance-real-by-the-second-9a97d12a): a bizarre idea that sounds like a joke until the business logic lands.

## The pitch

> We rent out trained goats to mow corporate lawns, charging facilities managers per acre, because goats undercut gardeners, never strike, and fertilise as they graze.

165 characters, one sentence.

## Why it meets the brief

- **Genuinely bizarre.** Renting livestock as lawn equipment sounds like a punchline — goats as a landscaping crew is not how anyone expects a startup pitch to open.
- **The business logic survives a second look.** Goatscaping is a real, existing service: goats eat weeds and grass, cost less than a gardening crew, need no fuel or mower maintenance, and fertilise the ground as they work. The pitch names the customer (facilities managers), the price model (per acre), and the cost advantage in the same breath.
- **It lands as a pitch.** The sentence does all the work in one line: the odd thing being sold (trained goats), who pays (facilities managers, per acre), and why it holds together (cheaper than gardeners, never strike, fertilise as they graze).

## Run it

```sh
python3 main.py
```

Writes the sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), after validating it: 1–200 characters, a single line, exactly one sentence, no leading/trailing whitespace, no control characters, no double spaces. Python 3.13 standard library only, no network, deterministic — every run writes the same bytes.
